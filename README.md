# 1. Music Artist and Genre Analysis Dashboard

This dashboard analyses music-related data to explore artist performance, musical genres and audio characteristics. The visualisations include a treemap of the top artists, comparisons of loudness by genre, artist rankings, time signature analysis, and relationships between liveness and popularity.

Key skills demonstrated:

Comparing data across artists and music genres

Creating treemaps, bar charts and combined charts

Exploring relationships between variables

Using visualisations to identify patterns and differences within a dataset

# 2.Industry and Employment Analysis Dashboard

This dashboard explores industry and employment-related data across the United Kingdom. It includes a bar chart comparing changes across industries, a geographical map showing regional data, a treemap highlighting industry categories, and bar charts comparing percentage change and employment figures across cities.

Key skills demonstrated:

Creating bar charts and treemaps

Geographic data visualisation using maps

Comparing industry trends and employment figures

Presenting multiple visualisations in an interactive dashboard
